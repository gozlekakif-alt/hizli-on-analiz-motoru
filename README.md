# Hızlı On Analiz Motoru v3

TXT, CSV veya Excel veri havuzunu yükleyerek çalışan Streamlit uygulaması.

## Kurulum

1. GitHub'da yeni repository oluştur.
2. `app.py`, `requirements.txt`, `README.md` dosyalarını yükle.
3. Streamlit Community Cloud'a GitHub ile giriş yap.
4. Repository'yi seç.
5. Main file path: `app.py`
6. Deploy.

## Özellikler

- Mükerrer çekiliş numaralarını temizleme
- Hatalı/eksik satırları raporlama
- Frekans ve dinlenme
- İkili ve üçlü birliktelikler
- Bant ve ardışık blok analizi
- Temiz CSV ve Excel indirme
